# 智能体的主动学习

持久智能体的 Codex 执行链会在当轮记录稳定偏好、明确纠正和已验证的跨会话事实。记录使用 `disco_agent_memory_save`；没有明确来源的记录默认标为推断。临时进度、凭据和未经验证的猜测不应作为长期事实保存。独立会话没有长期记忆，也没有复盘工具。

复杂任务结束前，智能体通过 `disco_agent_learning_review` 评估记忆和技能。有复用价值且经过实际验证的方法才通过现有 `disco_skills_install` 创建或更新，优先完善当前智能体的已有技能。没有值得保存的内容时，记录“无需更新”的判断即可。

执行器检查本轮是否提交了复盘。如果没有，遇到至少三次工作工具调用、记忆或技能保存、偏好/排错等提示、长请求或待整理记忆时，最多补一次收尾评估。补充评估在原任务内执行，默认上限 90 秒，计入该任务 Token 用量；失败不改变用户任务的成功结果。停止请求仍能中断它。用户在复盘期间追加指导时，恢复正常回复显示及用户任务的执行期限。

## 集中整理

每 8 次有效记忆更新，或者有效正文达到 12,000 字符且当前摘要失效时，触发集中整理。重复保存不增加计数；旧工作区不需要迁移，也参与阈值判断。

`inspect` 返回当前启用的原文和内容指纹；`complete` 提交精简摘要、该指纹及完整来源路径列表。摘要合并重复、保留重要约束、来源和不确定性；冲突优先采用明确纠正与更新的已验证事实。无法处理的冲突可以说明原因并延后，待整理状态保留。

状态、最近 64 次复盘及摘要写入智能体的 `.disco/learning.json`。原始主题记录继续保留在 `.disco/memory/`。只有原文指纹完全匹配时，预加载使用摘要；任何修改、停用或删除都会让旧摘要失效，回退到当前原文。服务拒绝提交过期的摘要，并验证当前任务、会话、智能体和用户的归属。

用户明确要求只读、不要记录或限定任务范围时，服从该要求。不会覆盖用户自定义人格，也不会启用 Codex Runtime Home 的共享原生记忆。
