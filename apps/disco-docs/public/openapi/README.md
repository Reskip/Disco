# OpenAPI snapshot

`disco.json` is generated by a current Disco daemon after all services have been
registered. It powers the public API reference; installed daemons continue to
serve their exact schema at `/docs.json`.

To refresh it, start the daemon from the release branch and run:

```bash
curl --fail --silent --show-error http://localhost:3030/docs.json \
  | jq . > apps/disco-docs/public/openapi/disco.json
```

Review the schema diff with the code change that altered the API.

The disco-live publish smoke test generates the schema from its fully registered
daemon and runs `scripts/check-openapi-snapshot.mjs`. It ignores only the
release-stamped `info.version`; endpoint and component drift fails CI.
