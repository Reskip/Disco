# 会话内提问

智能体和独立会话均可调用 `disco_ask_questions`，一次提出 1–3 个必要问题。前端显示单选、多选或自由输入卡片；不预选答案，任何问题都可以填写自己的答案。普通澄清不使用缺少浏览器交互的原生 `request_user_input` / `AskUserQuestion`；密码、API Key 等继续使用环境变量表单。

请求立即返回 `waiting_for_user`。这只表示问题已经显示，不代表用户作答或授权。模型可以继续独立工作，依赖答案时结束当轮。用户点击“提交并继续”或“跳过”后，沿用 widget 的持久化提交与任务接续机制，自动把答案送回原会话。重复点击不会重复创建后续任务；跳过明确表示未作答、未批准。

问题绑定当前正在运行的任务，持久化在 `widget_request` 消息中，刷新或切换会话后仍可回答。未提交草稿只保留在浏览器内存中，切换会话时保留，退出账号或删除会话时清理；刷新会清空草稿。已提交的答案可从消息恢复。

创建、读取和提交均使用已有的租户及会话所有权校验。提交端依据数据库里的原始问题校验问题 ID、选项和单选/多选约束。普通问题的答案会进入模型上下文，凭据表单的保密规则保持独立。
