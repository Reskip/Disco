# Codex 模型发现与旧配置兼容

Disco 通过执行环境内 Codex App Server 的 `model/list` 读取模型，包含分页、隐藏模型和思考深度；网页打开模型选择器时刷新，并每五分钟检查更新。登录切换清空浏览器缓存。后端每次解析实际执行用户的凭据与目录，不在不同用户之间共享发现结果。

模型选择器只展示模型名称，不展示供应商介绍，也不附加“推荐”“默认”“账号相关”等标签。隐藏模型不出现在新选项中，但已有选择仍可识别。获取失败时保留上次成功列表；没有成功记录时使用内置备用列表，并提示暂时无法更新。

已有用户默认、预设、会话模型都不做批量迁移。最新成功列表缺少已保存的普通模型时，显示原值和更换入口；只有用户操作才会改变配置。在设置页更换后仍须保存默认值；会话内更换只影响当前会话。新会话和运行配置校验拒绝不兼容的普通选择，并说明修复方法；刷新失败不判定模型失效。未配置模型的新会话使用发现结果的默认项，离线时使用内置备用值。

思考深度按所选模型的能力显示，不支持的旧值保留并提示更换；主动选择另一个模型时，保留兼容深度，否则使用其默认深度。精确锁定的模型 ID 可能不会出现在列表中，因此不以缺席判定失效，最终由 Codex 验证。历史消息、历史任务和用户配置都不因后台刷新而改变。

`model/list` 是当前已安装 Codex 的目录接口，可能使用 Codex 自己的缓存或内置列表，并非实时的账号授权验证。自动发现不代表自动升级 Codex CLI，也不会将备用列表当成完整可用性证明。推理时供应商返回的不可用错误仍然具有最终效力。

本地源码部署从执行器安装的 `@openai/codex-sdk` 依赖树解析 CLI，不使用桌面应用自带的 CLI。桌面应用升级不会更新 Disco。升级时须同步 core、executor、disco-codex 的 SDK 依赖、锁文件及 SDK 版本记录，并在运行目录安装对应依赖；只更新源码或全局 CLI 不生效。2026-10-08 已将依赖更新至 0.161.0；发布前须用隔离目录验证原生 `model/list` 和真实会话生命周期。
